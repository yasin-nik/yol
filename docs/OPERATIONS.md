# OPERATIONS

- **میزبانی:** سرور مجازی داخل ایران، به نام مالک، با دسترسی SSH. دامنه و SSL پس از G2.
- **درگاه:** زرین‌پال (مرجع: صفحه تعرفه و مستندات رسمی؛ کارمزد حدود ۰٫۵٪ تا سقف ۱۶ هزار تومان + ۵۰۰ تومان به‌ازای تراکنش، ماه اول فقط کارمزد شاپرک — پیش از خرید از سایت رسمی تأیید شود). callback باید از اینترنت ایران به سرور برسد؛ IP سرور در پنل زرین‌پال ثبت می‌شود.
- **پیامک:** adapter عمومی؛ ارائه‌دهنده در زمان اتصال واقعی انتخاب می‌شود.
- **بکاپ:** pg_dump روزانه به مکان جدا + یک restore آزمایشی ثبت‌شده (INV-12).
- **انتشار:** build، migration، env vars روی سرور، smoke test، دستور rollback مستند.
- **بار:** تست بار با ۵۰ کاربر هم‌زمان روی رزرو یک سانس ۱۰۰۰ صندلی (M8).

## محلی تا M3
- فعلاً فقط پیش‌نمایش روی `127.0.0.1:3100` و PostgreSQL پروژه روی ۵۴۳۳. در PowerShell محدود، بدون تغییر سیاست سیستم می‌توان مستقیماً pg_ctl نصب موجود را با `-D D:\YolTick\.local\pgdata -o "-p 5433" -l D:\YolTick\.local\pg.log -w start` اجرا کرد.
- `npm.cmd run migrate` تکرارپذیر است؛ نسخه‌های 0001 تا 0003 اعمال شده‌اند. `.env` و `.local/` در Git نیستند.
- `npm.cmd run holds:expire` دوره‌ای روی میزبان آینده اجرا شود (پیشنهاد یک دقیقه)؛ اکنون هیچ زمان‌بندی سیستم ساخته نشده و انقضا در خواندن/تغییر موجودی هم اِعمال می‌شود.
- next start با PAYMENT_GATEWAY=fake یا SMS_PROVIDER=fake شکست می‌خورد؛ پیش‌نمایش فعلی development است. پیش از تولید، DB نمایشی جدا بماند و مبدأ APP_ORIGIN، HTTPS، پراکسی معتبر و محدودیت IP بررسی شوند.
- `.local/demo-access.json` اطلاعات حساب محلی تولیدشده را دارد؛ آن را منتشر نکنید. تصاویر بازبینی در `.local/qa/` هستند.

## تکمیل عملیات M4/M5 — ۲۰۲۶/۱۱/۱۱

مهاجرت‌های افزایشی 0004 تا 0007 هویت مشتری، سفارش، پرداخت و بلیت را اضافه می‌کنند؛ برای ارتقا داده مالی را حذف نکنید. ابتدا npm.cmd run payments:reconcile برای استعلام PENDING/UNKNOWN؛ سپس npm.cmd run holds:expire برای آزادسازی رزروهای قابل انقضا. اجرای دوره‌ای دقیقه‌ای پیشنهاد است؛ هیچ زمان‌بندی واقعی ایجاد نشده. وضعیت نامشخص صرفاً با گذر زمان آزاد نمی‌شود. reconcile شمارنده و خطای بدون اسرار می‌دهد و در صورت خطا با کد ناموفق خارج می‌شود.

Fake شناسه درخواست تکرارپذیر، وضعیت ذخیره‌شده و انقضا دارد؛ شبیه‌ساز نیازمند مالکیت حساب است و در production ممنوع است. آزمون‌ها، مهاجرت تکراری، lint/typecheck/build، reconcile و audit واقعاً اجرا شدند؛ جزئیات در QA-M5.md. cache وابستگی‌ها برای فرمان‌های بعدی می‌تواند با npm_config_cache=D:\YolTick\.local\npm-cache داخل پروژه بماند؛ نصب global یا تغییر سیستم انجام نشد.

## M6/M7 — ۲۰۲۶/۱۱/۱۱
مهاجرت‌های 0008/0009 افزایشی‌اند و سوابق مالی را فقط‌افزودنی می‌کنند؛ برای اصلاح از ثبت معکوس/روند استرداد استفاده شود، نه DELETE/TRUNCATE. قبل از تسویه، محاسبات فاقد snapshot و سفارش‌های REVIEW را تکمیل کنید؛ پس از تمام سانس‌ها و تأیید انجام پرداخت، مرجع تسویه یکتا ثبت شود. استرداد کل سفارش دو مرحله دارد: درخواست/ابطال QR سپس ثبت مرجع بازگشت وجه انجام‌شده؛ هیچ انتقال بانکی انجام نمی‌شود.

پیش‌نمایش این نشست در .local/next-preview جدا از .next است؛ مرور از http://localhost:3100 توصیه می‌شود. نسخه قدیمی صفحه روی 127.0.0.1 اسکریپت ورود cache‌شده ناسازگار داشت؛ نشست تازه localhost با موفقیت ورود بررسی شد. حساب مالک فقط لوکال و دارای local_only است؛ رمز/ایمیل پیکربندی در .env، بدون نمایش در لاگ برنامه و بدون درج رمز در Git. اجازه دوربین برای localhost یا HTTPS لازم است؛ تا پاسخ معتبر سرور صادر نشده اجازه ورود ندهید.
