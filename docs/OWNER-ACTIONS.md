# OWNER-ACTIONS — فقط کارهای مالک (ایجنت دخالت نمی‌کند، جز یادآوری)

DEPLOYMENT.md قدم‌ها را توضیح می‌دهد؛ هیچ حسابی در M8 خریداری یا متصل نشد.
