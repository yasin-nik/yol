# گزارش آماده‌سازی انتشار عمومی بدون فروش — ۲۰۲۶/۱۱/۱۵

## وضعیت
کد M0 تا M8 قبلاً تکمیل و در تگ `m8` متوقف شده بود. این گزارش مربوط به آماده‌سازی انتشار عمومی برای معرفی، دریافت مجوز و بررسی دامنه است؛ فروش واقعی در این مرحله فعال نیست.

## تغییرات
- آداپتورهای `disabled` برای پرداخت و پیامک اضافه شد.
- production فقط با `PAYMENT_GATEWAY=disabled`، `SMS_PROVIDER=disabled` و `REAL_SALES_ENABLED=false` بالا می‌آید.
- مسیرهای OTP و پرداخت در این حالت با خطای کنترل‌شده ۵۰۳ پاسخ می‌دهند.
- فرمان `start:public-preview` و راهنمای `.env`/Nginx اضافه شد.
- تصمیم در `docs/DECISIONS.md` با شماره D-042 ثبت شد.

## اعتبارسنجی واقعی
- `npm run lint` — موفق
- `npm run typecheck` — موفق
- `npm run build` — موفق
- اجرای `next start` با تنظیم production preview — موفق
- صفحه اصلی — HTTP 200
- `/api/health` — HTTP 200 و `{"status":"ok"}`
- هدر CSP — فعال

## باقی‌مانده
سرور ایران، دامنه، HTTPS، Nginx، بکاپ خارج از سرور و اتصال درگاه/پیامک واقعی هنوز انجام نشده‌اند. این موارد پس از تهیه سرور و تصمیم مالک برای عبور از G2/G3 انجام می‌شوند.
