# QA M8 — ۲۰۲۶/۱۱/۱۱

M8 تکمیل مهندسی محلی است؛ G3 و آمادگی انتشار production تأیید نشده‌اند. هیچ پول/پیامک/کاربر واقعی یا سرویس عمومی در این مرحله فعال نشد.

## واقعاً اجرا شد
- فقط `tests/m8-load.test.ts`، `m8-backup.test.ts`، `m8-security.test.ts` و `m8-catalog.test.ts`: ۱۰ تست موفق، صفر شکست/skip در اجرای نهایی. تست‌های مراحل قبل اجرا نشدند؛ fixtureهای مشترک صرفاً داده آزمایش این مرحله ساختند.
- بار سرویس با PostgreSQL واقعی و pool=10: ۵۰ مشتری با نشست آزمایشی، هر کدام ۲۰ صندلی؛ ۱۰۰۰ صندلی SOLD، ۱۰۰۰ بلیت یکتا، ۵۰ سفارش PAID، ۵۰ snapshot مالی؛ بازپخش ۵۰ callback بدون تکرار. فقط درگاه Fake است؛ رزرو/سفارش/تأیید/صدور واقعی‌اند. رقابت جداگانه ۵۰ نفر روی یک صندلی: ۱ موفق و ۴۹ تعارض 409، بدون خطای غیرمنتظره.
- آخرین p95 سرویس‌ها: رزرو ۲۵۳ms، سفارش ۳۹۹ms، شروع پرداخت ۱۵۳ms، تأیید/صدور ۵۵۷ms، callback تکراری ۵۱ms، موجودی ۵۷۴ms. آستانه آزمایشی هر عملیات ۱۵ ثانیه؛ نتیجه سخت‌افزار محلی و gateway Fake است.
- `qa:m8:http`: Next development جدا روی loopback:3108 و yoltick_test؛ ۵۰ پاسخ 200 با هر کدام ۱۰۰۰ صندلی، p95=1434ms و max=1466ms پس از warm-up. تطابق nonce هدر/HTML، حذف X-Powered-By، health، منع مبدأ جعلی 403، حجم زیاد 413 و دو مسیر خصوصی 401 تأیید شد. این بار HTTP فقط خواندن موجودی است؛ خرید کامل در سطح سرویس آزموده شد.
- `pg_dump` custom و `pg_restore --single-transaction --exit-on-error` واقعاً اجرا شدند: ۳۱ جدول، ۳۸۴۴۵ ردیف، هش محتوای تمام جداول برابر؛ تعاریف قیود، index، trigger و تابع هم برابر. بازیابی ۸۳۳ms؛ check-in استفاده‌شده حفظ و درج مجدد/حذف آن رد شد. مقصد آخر `yoltick_restore_1794412564789`؛ هیچ DB قبلی حذف نشد. checksum و گزارش در `.local/backups` محفوظ‌اند.
- فرمان `npm run backup` جداگانه روی yoltick_dev اجرا و archive/checksum جدید ساخت؛ خارج ماشین منتقل نشد.
- `typecheck`، lint فایل‌های تغییرکرده و production build موفق. `npm audit --json`: صفر آسیب‌پذیری از ۵۳۴ وابستگی گزارش‌شده. اسکن مقادیر محرمانه بلند پیکربندی در فایل‌های tracked و JS کلاینت build بدون افشا؛ `.env` tracked نیست. این اسکن جایگزین بازبینی انسانی یا شناسایی همه انواع secret نیست.
- اجرای واقعی `next start` با Fake عمداً با خطای مورد انتظار متوقف شد. آزمون M8 provider خالی/ساختگی و APP_ORIGIN بدون HTTPS را هم رد کرد. پرچم فروش واقعی بدون G3 پیش‌فرض خاموش است.

## بازبینی جداگانه و اصلاح‌ها
پس از پیاده‌سازی، دور جداگانه مرور کد/مسیرهای API/SQL و تنظیمات انجام شد؛ همان عامل، نه بازبین ثالث یا متخصص انسانی. کنترل authz در سرویس‌های سرور، مالکیت بلیت/سفارش، مبدأ تغییرات، ورودی stream، عدم اعتماد به IP ارسالی، نرخ‌های DB و حفظ قیود مالی بررسی شد. فایل آپلود/سرویس خارجی runtime در این نسخه وجود ندارد؛ فونت و QR محلی‌اند.

یافته‌های رفع‌شده: نبود CSP/هدرهای حفاظتی؛ startup قابل عبور با نام ساختگی provider؛ نبود ابزار بازیابی؛ نبود health/لاگ عمومی امن خطا؛ میان‌بر محتوای پوشیده زیر header؛ نبود جست‌وجو/فیلترهای ذکرشده در PRD. CSP script با nonce و strict-dynamic، unsafe-eval فقط توسعه؛ inline style برای سازگاری رابط باقی است. پس از فیلتر زمان، قیمت و اولین سانس از همان مجموعه مجاز محاسبه می‌شوند.

Chrome با مهارت رسمی، فقط DOM/CUA/screenshot، بدون هیچ استفاده از Playwright: دسکتاپ و موبایل ۳۷۵×۸۱۲، RTL، فوکوس Tab/میان‌بر محتوا، ناوبری رویداد/سانس، فرم جست‌وجو، پاک‌کردن و حالت بدون نتیجه بررسی شدند. تصویرها `.local/qa/m8-desktop.jpg` و `m8-mobile.jpg`. نبود خطای CSP در کنسول مسیرهای مشاهده‌شده بررسی شد؛ دوربین فیزیکی و چاپ در این نشست آزموده نشد.
