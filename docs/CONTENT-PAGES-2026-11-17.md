## محدوده

## تغییرات محدود
فقط چهار فایل صفحه، `src/components/info-page.tsx` برای قالب خوانای مشترک و `src/components/shell.tsx` برای لینک درباره ما وارد بستهٔ سرور می‌شوند. هیچ وابستگی برنامه، تنظیم محیط، دیتابیس، دسترسی، درگاه یا پیامکی تغییر نمی‌کند. مستندات، تست‌ها، فایل پیوست و ابزارهای موقت محلی به سرور منتقل نمی‌شوند. تغییر مستقل قبلیِ متادیتای صفحهٔ اصلی روی سرور حفظ می‌شود.

## آزمون‌های واقعی لوکال
- `npm.cmd run lint`، `npm.cmd run typecheck` و `npm.cmd run build`: موفق.
- اجرای production با پرداخت/پیامک disabled و فروش خاموش؛ هر چهار مسیر HTTP 200، مقالهٔ محتوا موجود و متن موقت غایب بود.
- تطبیق ماشینی تمام بندهای پیوست با HTML چهار صفحه، با نادیده‌گرفتن فاصله و براکت نمایشی: موفق؛ تاریخ فارسی جداگانه بررسی شد.
- Chrome: مشاهدهٔ تماس در دسکتاپ، درباره ما و قوانین؛ قوانین در عرض موبایل، RTL و بدون بیرون‌زدگی افقی بود.
- آزمون تراکنش/دیتابیس اجرا نشد؛ این تغییر فقط محتوا و قالب صفحات است.
